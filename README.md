# 🏀 CoachFlow (Beta)
## Sydney's Premier Basketball Coaching Marketplace

**Seamlessly connecting verified basketball coaches with schools, clubs, PCYC programs, and organizations across Greater Sydney.**

🌟 **Now in Beta:** Experience our lightning-fast platform with real-time notifications, dark mode, and intelligent matching - all completely FREE during our beta period.

### 🎯 **The Problem We're Solving**

**For Coaches:**
- Struggling to find consistent coaching opportunities across Sydney
- Spending hours on phone calls and emails just to get trial sessions
- Getting paid late or dealing with unclear payment terms
- Having your coaching credentials questioned repeatedly
- Missing out on opportunities because you don't know the right people

**For Organizations:**
- Desperate searches for qualified coaches, especially for school holidays and weekend programs
- Uncertainty about coach qualifications and Working with Children Checks
- Last-minute cancellations leaving parents disappointed and programs understaffed
- Administrative overhead of managing multiple casual coaches
- Difficulty finding specialized coaches (elite development, junior programs, disability basketball)

### 💡 **Our Solution**

CoachFlow is a **verified marketplace** that connects Sydney's basketball coaches with organizations that need them. Think of it as "Seek for Basketball Coaches" - but better, because we understand the unique needs of our sport.

## 🚀 **Getting Started (For Developers)**

### **Quick Setup**

```bash
# Clone the repository
git clone https://github.com/AryasKeeper/CoachFlow-v01.git
cd coachflow

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env.local
# Edit .env.local with your Supabase credentials

# Run database migrations
npx supabase db push

# Start development server with Turbopack
npm run dev

# Access the app at http://localhost:3000
```

### **Environment Configuration**

Create a `.env.local` file with these variables:

```env
# Database (Supabase)
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_anon_key
SUPABASE_SERVICE_ROLE_KEY=your_service_role_key

# AI Features (Optional)
OPENAI_API_KEY=your_openai_api_key
AI_MODEL=gpt-4

# Security
JWT_SECRET=your_jwt_secret_key
NEXTAUTH_SECRET=your_nextauth_secret

# Email (Choose one)
RESEND_API_KEY=your_resend_key
# OR
SENDGRID_API_KEY=your_sendgrid_key

# Payments (Future)
STRIPE_PUBLISHABLE_KEY=pk_test_...
STRIPE_SECRET_KEY=sk_test_...
```

## 🚀 **Production Deployment**

### **Automated Deployment with Vercel**

CoachFlow includes professional CI/CD pipelines for reliable deployments:

1. **Push to GitHub** → Automatic testing and security scans
2. **Deploy to Staging** → Full integration testing  
3. **Deploy to Production** → Blue-green deployment with health checks

### **Manual Deployment Steps**

```bash
# 1. Build for production
npm run build:prod

# 2. Test the production build locally
npm run start:prod

# 3. Deploy to Vercel
npm run deploy:production

# 4. Run post-deployment health checks
npm run health:check
```

## 💡 **Development Guidelines**

### **Code Quality Standards**
- **TypeScript First:** All new code must use TypeScript with strict typing
- **Component Architecture:** Keep components focused, reusable, and well-documented
- **Performance:** Optimize for Core Web Vitals (<2.5s LCP, <100ms FID, <0.1 CLS)
- **Accessibility:** WCAG 2.1 AA compliance minimum
- **Dark Mode Support:** All new components must support both themes
- **Real-time Ready:** Consider WebSocket subscriptions for live features
- **Mobile First:** Design for mobile, enhance for desktop

### **Testing Requirements**
- **Unit Tests:** >80% coverage for utilities and components
- **Integration Tests:** All API endpoints and database interactions
- **E2E Tests:** Critical user journeys for both coaches and organizations
- **Performance Tests:** Page load and interaction benchmarks

### **Development Commands**
```bash
# Start development with Turbopack
npm run dev

# Build for production
npm run build

# Run production build locally
npm run start

# Type checking
npm run type-check

# Linting
npm run lint

# Run tests
npm run test

# Run E2E tests
npm run test:e2e

# Database migrations
npx supabase migration new <name>
npx supabase db push

# Generate TypeScript types from database
npx supabase gen types typescript --local > types/supabase.ts
```
