## 📱 What to Test

### For Coaches (Blue Path)
1. **Sign In** with the coach test account
2. **Complete Your Profile**
   - Add a photo (optional)
   - Write a short bio
   - Select your coaching specialties
   - Add suburbs where you can work
   - Set your hourly rate
3. **Upload Verification** (optional for testing)
   - Working with Children Check (required for real coaches)
   - First Aid & Insurance (optional enhancements)
4. **Browse Jobs**
   - Look at available coaching positions
   - Try different filters (location, type, etc.)
5. **Apply for a Job**
   - Click "Apply" on any listing
   - Write a short message with your application
6. **Check Messages**
   - See if you have any messages from organizations

### For Organizations (Green Path)
1. **Sign In** with the organization test account
2. **Complete Organization Profile**
   - Add organization details
   - Upload a logo (optional)
3. **Post a Job Listing**
   - Click "Post a Job"
   - Fill in job details (title, location, description)
   - Set requirements and pay rate
4. **Review Applications**
   - Check "My Applications" to see who applied
   - View coach profiles
   - Accept or decline applications
5. **Message Coaches**
   - Send messages to coaches you're interested in

## 🐛 What We're Looking For

### Please Note:
- ✅ **What works well** - Features that are smooth and easy
- ❌ **What's confusing** - Anything that's unclear
- 📱 **Mobile issues** - Problems on your phone
- 🐌 **Slow loading** - Pages that take too long
- 💔 **Errors** - Any error messages or broken features

### How to Report Issues:
1. **Take a screenshot** (if possible)
2. **Note what you were trying to do**
3. **Send feedback via:**
   - Text message
   - Email
   - Or use the messaging feature in the app!

## 💡 Testing Tips

### On Mobile:
- Try both portrait and landscape modes
- Test on WiFi and mobile data
- Check if buttons are easy to tap

### On Desktop:
- Try different browsers (Chrome, Safari, Firefox)
- Resize the window to see how it adapts
- Test with mouse and keyboard navigation

## 🎯 Key Features to Test

1. **Sign Up Process**
   - Is it clear which type of account to create?
   - Are the forms easy to fill out?

2. **Profile Creation**
   - Can you easily add all your information?
   - Is it clear what's required vs optional?

3. **Job Listings**
   - Are listings easy to read and understand?
   - Can you filter to find relevant jobs?

4. **Application Process**
   - Is applying for jobs straightforward?
   - Can you track your applications?

5. **Messaging**
   - Can you send and receive messages?
   - Are notifications working?
